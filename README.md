# Sterling Commerce Solutions

Preview site for the Sterling Commerce Solutions e-commerce services business.

## Deploy

Static HTML at repository root; deploy with Vercel using Other framework.

## Before public launch

- Verify legal business name, address, contact email, and legal disclosures.
- Connect an actual consultation form and privacy notice.
- Verify portfolio links and business-sale marketplace terms.
- Review published prices and service scope.
- Add the registered domain only after owner approval.
- Confirm Google Merchant Center service disclaimers.
